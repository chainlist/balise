# Quoi de neuf dans Balise 0.42.0

### Épinglez vos notes importantes
Vos notes les plus consultées peuvent désormais être **épinglées en haut de la liste**.

- **Survolez une note** dans la liste : une **punaise** apparaît en haut à droite pour l'épingler ou la détacher. L'action est aussi disponible dans le menu **« ... »** de la note.
- Les notes épinglées sont **regroupées en haut de la liste**, sous un intitulé **« Épinglées »**, les autres suivant sous **« Notes »**.
- Quand plusieurs notes sont épinglées, elles sont **classées par ordre alphabétique**. Les accents sont rangés avec leur lettre de base : « Éclair » se place bien entre « date » et « fig ».
- Un filtre **« Épinglées »** apparaît dans la barre latérale, juste sous **« Sans tag »**, dès qu'une note est épinglée : il n'affiche que celles-ci.
- L'épinglage est enregistré **dans le fichier de la note** et **se synchronise** avec vos autres appareils, comme le reste de son contenu.

### Exportez une note en PDF ou en image
Le menu **« ... »** d'une note propose un nouveau sous-menu **« Exporter »**, avec trois formats : **PDF**, **image PNG** et **image JPEG**.

- La note est mise en page **comme un document**, et non comme une capture de l'éditeur : titre, mise en forme, listes, tableaux, images et citations sont rendus proprement.
- L'export est généré en **haute résolution**, pour rester net à l'impression comme au zoom.
- Le **nom du fichier** est proposé automatiquement à partir du titre de la note, et vous choisissez où l'enregistrer.
- L'export reprend **les couleurs de votre thème** : si vous utilisez un thème sombre, le document exporté le sera aussi.
- Le PDF tient sur **une seule page, à la largeur d'une A4**, aussi haute que nécessaire : une note longue donne donc une page longue.

### Démarrez vos notes à partir d'un modèle
Une nouvelle section **Modèles de note** dans les réglages permet de définir le contenu de départ des nouvelles notes.

- Chaque modèle porte un **nom** et un **contenu** en markdown, et vous pouvez en créer autant que vous voulez.
- L'un d'eux peut être désigné **modèle par défaut** (l'étoile) : il sert alors pour **toute nouvelle note**, y compris celles créées au clavier avec **Ctrl/Cmd + N**.
- Le bouton **« + »** de la liste des notes reçoit un **chevron** dès qu'un modèle existe : il ouvre la liste pour choisir un modèle ponctuellement, ou créer une **note vierge**.
- Le **centre de commandes** (Ctrl/Cmd + K) liste aussi vos modèles : tapez le nom de l'un d'eux et validez pour créer aussitôt une note à partir de ce modèle.
- Le contenu d'un modèle s'écrit maintenant dans **l'éditeur de notes lui-même** : le markdown y est rendu comme dans une vraie note (titres, listes, cases à cocher, tableaux, tags), au lieu du simple champ de texte précédent.
- Tapez `{{` dans un modèle pour ouvrir la **liste des variables**, chacune avec une courte description. Les variables reconnues sont **mises en évidence** dans le modèle, une faute de frappe reste en texte brut.
- Les **variables** disponibles, toutes remplacées à la création de la note :
  - `{{title}}` : le titre par défaut d'une nouvelle note
  - `{{date}}` : la date du jour, dans le format de date que vous avez choisi
  - `{{time}}` : l'heure actuelle
  - `{{datetime}}` : la date et l'heure du jour
  - `{{weekday}}` : le jour de la semaine
  - `{{month}}` : le mois en cours
  - `{{year}}` : l'année en cours
  - `{{tag}}` : le tag actif, s'il y en a un
  - `{{cursor}}` : l'endroit où se place le curseur à l'ouverture de la note
- `{{cursor}}` n'insère rien : il est **retiré du texte**, et marque seulement où commencer à écrire. Si vous en mettez plusieurs, **seul le premier compte**, les autres sont retirés eux aussi.
- Le modèle **remplace le titre « Nouvelle note »** habituel, mais le **tag actif reste ajouté** : créer une note depuis un tag continue d'insérer son hashtag.
